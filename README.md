## Features

- **AI Study Mentor** — explains any topic clearly and deeply
- **Visual Explanations** — colorful diagrams and formatted responses
- **PDF Export** — save any response as a PDF instantly
- **Coding Assistant** — efficient code with clear explanations
- **Deep Research Mode** — web search integrated answers
- **100% Offline** — powered by Llama 3.1 via Ollama

## Installation

1. Install [Ollama](https://ollama.com/download)
2. Pull the AI model:
```bash
   ollama pull llama3.1:8b
```
3. Clone this repository:
```bash
   git clone https://github.com/yourusername/Mint.ai.git
   cd Mint.ai
```
4. Install dependencies:
```bash
   npm install
```
5. Start the app:
```bash
   npm start
```
